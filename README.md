# CivicAI 360 — Local Hackathon Website

CivicAI 360 is a Flask + SQLite civic complaint-management prototype. It includes citizen reporting, role-based workspaces, rule-based complaint categorization and prioritization, related-issue suggestions, geographic hotspot grouping, department workflows, status timelines, feedback, and CSV export.

**Important:** This is a hackathon prototype. Its local AI features are deterministic rules and similarity signals, not a connected large language model. Demo records and map coordinates are synthetic. It is not connected to a real government service.

## Requirements

- Windows 10/11, macOS, or Linux
- Python 3.10 or newer
- Internet access only for optional map tiles, fonts, and Leaflet assets

No Node.js is required for this version.

## Start on Windows (VS Code)

1. Extract `CivicAI360.zip`.
2. Open the extracted `CivicAI360` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Create a virtual environment:

   ```powershell
   python -m venv .venv
   ```

5. Activate it:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt terminal and run:

   ```bat
   .venv\Scripts\activate.bat
   ```

6. Install packages:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

7. Start the website:

   ```powershell
   python app.py
   ```

8. Open **http://127.0.0.1:5000** in your browser.

Keep the terminal open while using the website. Press `Ctrl+C` in the terminal to stop it.

## Demo workflow

1. Sign in as `citizen` and submit an issue.
2. Add a title, description, location, and optional coordinates/photo.
3. Open the generated complaint reference.
4. Review the summary, category, explainable priority score, related issue suggestions, and timeline.
5. Sign out and sign in as `admin`.
6. Open a complaint and assign a department, update status, and add a public progress message.
7. Use **Issue Link** to review potential related reports.
8. Use **Hotspots** to inspect groups formed from synthetic coordinates.
9. Sign in as the citizen and review the progress timeline.

## Data

The SQLite database `civicai.db` is created automatically the first time `app.py` runs. Ten synthetic demonstration complaints are inserted only when the complaints table is empty. A new complaint persists across restarts.

To reset local demo data, stop the server, delete `civicai.db`, and run `python app.py` again. This deletes local complaint records, accounts, and history; back up anything important first.

Uploaded images are stored in `static/uploads/`.

## Main routes

- `/` — public landing page
- `/login` — sign-in
- `/dashboard` — role-specific workspace
- `/complaints/new` — report a problem
- `/complaints/<id>` — complaint detail and workflow
- `/admin/relationships` — administrator review of related issue suggestions
- `/admin/hotspots` — geographic grouping and map
- `/admin/export.csv` — administrator-only CSV export
- `/api/health` — basic application health response

## Current limitations

- Category and priority results use transparent local rules; they are not generated by a hosted LLM.
- Similarity scores are heuristic signals, not calibrated probabilities.
- Hotspots use a simple latitude/longitude grid, not official geographic boundaries.
- The map, tile layer, Leaflet, and web fonts need internet access. A complaint list and other core pages work without the map.
- Authentication is suitable for local demonstration only; add CSRF protection, production session settings, rate limiting, and deployment hardening before public deployment.
- The prototype does not send real email/SMS messages or connect to government departments.
- Citizen identity and location details should be reviewed carefully before any real-world deployment.

## Troubleshooting

**`python` is not recognized:** Install Python 3.10+ from the official Python website and enable the option to add Python to PATH, then reopen VS Code.

**`pip` is not recognized:** Try `python -m pip install -r requirements.txt`.

**Port 5000 is already in use:** Close the other application using the port or change the port in the final `app.run(...)` line in `app.py`.

**Map is blank:** Check internet access. Map tiles are loaded from OpenStreetMap.

**Want a clean demo database:** Stop the server, delete `civicai.db`, and restart `python app.py`.
